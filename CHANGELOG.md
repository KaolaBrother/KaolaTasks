# Changelog

## Unreleased

- `@kaola/server`: multi-source OAuth (GitHub / GitLab / Gitea) with `@fastify/oauth2@^8.3.0`, `@fastify/cookie@^11.1.2`, `@fastify/session@^11.1.2`. `users` table columns `id`, `provider`, `remote_id`, `username`, `display_name`, `status`, `permission_level`; UNIQUE `(provider, remote_id)`. `status` `active` | `待批准`; `permission_level` `full` | `claim_only`; `provider` `github` | `gitlab` | `gitea`. HTTP: `GET /login`; OAuth start `GET /login/github`, `/login/gitlab`, `/login/gitea`; callbacks `GET /login/github/callback`, `/login/gitlab/callback`, `/login/gitea/callback`; `GET /api/v1/me`; `POST /api/v1/users/:id/approve` (actor must be `active` + `full`; sets target `status` to `active`; GitHub stays `claim_only`). Pending `GET /api/v1/me` includes `message` `你的账号待正式成员批准后方可认领任务。`. `GET /` still `text/plain; charset=utf-8` body `考拉任务服务占位`. `registerAuth` requires non-empty `SESSION_SECRET`, `OAUTH_GITHUB_CLIENT_ID`, `OAUTH_GITHUB_CLIENT_SECRET`, `OAUTH_GITLAB_CLIENT_ID`, `OAUTH_GITLAB_CLIENT_SECRET`, `OAUTH_GITLAB_BASE_URL`, `OAUTH_GITEA_CLIENT_ID`, `OAUTH_GITEA_CLIENT_SECRET`, `OAUTH_GITEA_BASE_URL`. Optional `PUBLIC_URL` default `http://localhost:3000`. `SQLITE_PATH` default `:memory:`. MCP, task CRUD, vault, and claim still unimplemented.
- `@kaola/web`: Chinese Naive UI (`zhCN`) login buttons to `/login/github|gitlab|gitea`; pending card; 正式成员 approve by user id. Vite proxy `/api` and `/login` → `http://127.0.0.1:3000`. No vue-router.
- `@kaola/forge-adapters`: `createForgeAdapter(kind, options?: { baseUrl?: string })` implements `kind` + `validateToken` (global `fetch`, GET-only). Types: `ForgeKind`, `Credential` `{ token: string }`, `RepoRef` `{ full_name: string; base_url: string }`, `TokenCapability` `'读'|'推'|'PR'`, `TokenCheck` `{ missing: TokenCapability[] }`, `CreateForgeAdapterOptions`, `ForgeAdapter`. Placeholders `ImportedIssue`, `PrStatus`, `ForgeEvent`, `IssueRef` are `unknown`. Other interface methods throw `Error('not implemented')`. GitHub API host always `https://api.github.com` (ignores `baseUrl`); GitLab join strips trailing slashes then `/api/v4`; Gitea `/api/v1`. No runtime HTTP dependency. Push/PR checks are REST permission proxies, not mutating git push / POST PR. `getForgeAdaptersHealth()` still returns `kaola-forge-adapters-ready`.
